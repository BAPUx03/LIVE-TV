# LIVE-TV

A web-based TV streaming interface providing access to live channels. Built for lightweight performance and easy access to multiple streams.

## 🔴 Live Demo

[![Live Button](https://img.shields.io/badge/Live-TV-red?style=for-the-badge&logo=television)](https://bapux03.github.io/LIVE-TV/)

## 🚀 Features

- Clean and responsive UI
- Easy navigation of available channels
- Fast streaming access
- Works on both desktop and mobile browsers

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages for hosting
